# Бочкарев Виталий ИТ-9 Лабораторная #3

**Задача 1 (1.6)**
Отдельные линии. 
Измените сущность Линия из задачи 1.5.3. Необходимо, чтобы Линия соответствовала следующим требованиям: 
• Две любые линии не могут ссылаться на один и тот же объект точки. 
• У Линии можно изменить координаты начала или конца 
• У Линии можно запросить координаты начала или конца 
Продемонстрируйте работоспособность решения на примерах. 
**Алгоритм решения:** Заключается в обеспечении полной изоляции объектов точек внутри сущности линия для предотвращения побочных эффектов разделения памяти. При инициализации объекта через координаты или посредством передачи готовых объектов Point применяется техника защитного глубокого копирования, когда внутри конструктора извлекаются числовые значения параметров и создаются абсолютно новые, независимые экземпляры точек в куче. Аналогичный подход используется в геттерах и сеттерах: методы getStart и getEnd возвращают не оригинальные ссылки на внутренние поля, а новые объекты-копии, что полностью исключает несанкционированное изменение геометрии отрезка из внешнего кода. Прямое изменение и запрос координат реализуются через выделенные методы модификации setStartCoordinates и setEndCoordinates, обновляющие состояние точек внутри класса.

По запросу Квадрат математически высчитывает координаты остальных трёх своих углов по часовой стрелке. Эти четыре точки сохраняются в обычный массив Point фиксированной длины и передаются в конструктор класса Lomanaya. Внутри ломаной запускается цикл, который последовательно считает расстояния между соседними точками массива по формуле Пифагора и складывает их в общую длину.

**Задача 3 (2.1)** 
Неизменяемый массив.
Необходимо разработать сущность НеизменяемыйСписокЗначений, представляющий собой обертку над массивом целых чисел, который сохранит функциональные возможности массивов, но добавит некоторые дополнительные возможности. Состояние сущности описывают следующие сведения:
• Имеет массив целых чисел. Именно он используется для хранения значений.
Инициализация сущности может быть выполнена следующим образом: 
• С указанием значений в виде массива целых чисел. 
• С указанием перечня чисел как независимых значений (через запятую) 
• С указанием другого Списка, в этом случае копируются все значения указанного списка. 
Поведение сущности описывают следующие действия: 
• Получение значения из позиции N. Позиция должна попадать в диапазон от 0 до N-1, где N–текущее количество значений, иначе выкинуть ошибку.
• Замена значения в позиции N на новое значение. Позиция должна попадать в диапазон от 0 до N-1, где N–текущее количество значений, иначе выкинуть ошибку. • Может быть приведен к строке. Строка должна представлять собой полный перечень всех хранимых чисел, причем первый символ строки это ”[“, а последний “]”. • Можно проверить пуст Список или нет. Список пуст если его размер 0. • Можно узнать текущий размер.
• Все хранящиеся значения можно запросить в виде стандартного массива. 
Продемонстрируйте работоспособность решения на примерах. 
**Алгоритм решения:** Заключается в создании безопасной обёртки над стандартным массивом чисел для защиты данных от изменений извне. При создании объекта конструктор принимает массив и копирует все числа в новое скрытое поле через метод System.arraycopy, полностью разрывая связь с исходным массивом. Методы получения и замены значений проверяют переданный индекс, и если он выходит за рамки массива, выбрасывают контролируемую ошибку. Методы размера и проверки на пустоту возвращают длину массива. Метод вывода также выдаёт наружу новую независимую копию чисел, а метод toString собирает все элементы в строку в квадратных скобках.

**Задача 4 (3.5)** 
Трехмерная точка.
Создайте такой подвид сущности Точка из задачи 1.1.1, которая будет иметь не две, а три координаты на плоскости: X,Y,Z. 
**Алгоритм решения:** Заключается в создании Трёхмерной точки путём расширения базового класса Point с помощью механизма наследования extends. При инициализации объекта конструктор принимает три координаты и первой строкой вызывает родительский конструктор через super(x, y), что обеспечивает правильную инициализацию базовых осей в памяти, после чего отдельно фиксируется собственная координата z. Класс инкапсулирует новое свойство с помощью стандартных методов доступа getZ и setZ. Для корректного вывода объекта на экран применяется переопределение метода toString, который заменяет родительскую логику отображения двух координат и собирает новое строковое представление в формате {x;y;z}.

**Задача 5 (4.5)** 
Точки. 
Необходимо разработать сущности, которые позволят создавать Точки координат с разными характеристиками. Например, мы можем иметь точки координат со следующими характеристиками: 
• Одна, две или три координаты в пространстве (X,Y,Z: целые числа) 
• Цвет точки (строка) 
• Время появления точки (строка) Обратите внимание, что эти характеристики не составляют исчерпывающий список (так как в будущем могут появиться новые характеристики) и могут составлять любые комбинации, например:
• Точка в координате 3, красного цвета 
• Точка в координате {4,2,5} в 11:00 
• Точка в координате {7,7} в 15:35, желтого цвета 
С целью совместимости с последующими задачами, сохраните Двухмерную и Трёхмерную точки из задачи 2.3.5 без изменений. 
**Алгоритм решения:** Базовый класс Point объявляется абстрактным, фиксируя обязательное наличие двух базовых осей координат, но запрещая создание «пустой» геометрической точки без конкретных свойств. На основе абстрактного класса с помощью механизма extends конструируются специализированные подклассы под каждую уникальную комбинацию параметров: ColoredPoint (для точки с цветом), TimedPoint3D (для трёхмерной точки со временем) и TimedColoredPoint (для точки с цветом и временем одновременно). Каждый подкласс первой строкой вызывает родительский конструктор через super для передачи координат наверх, после чего инициализирует собственные уникальные строковые свойства. Окончательное формирование объектов завершается через переопределение методов toString, где каждый подкласс самостоятельно решает, как красиво склеить координаты и свои новые характеристики в единую текстовую строку.

**Задача 6 (5.1)** 
Сложение.
Разработайте метод, который принимает набор числовых значенийи возвращает их сумму в вещественной форме. 
С использованием данного метода выполните следующие сложения: 
• 2+3/5+2.3 
• 3.6+49/12+3+3/2 
• 1/3+1 
**Алгоритм решения:** Заключается в реализации универсального математического метода sum, способного принимать и суммировать произвольное количество числовых данных в единую вещественную форму. Внутри метода запускается цикл for-each, который последовательно перебирает элементы массива и аккумулирует их значения в итоговую переменную типа double. При вычислении выражений с обыкновенными дробями деление чисел в аргументах метода принудительно записывается в вещественной форме с плавающей точкой. Это позволяет обойти стандартное целочисленное деление Java, исключить потерю остатка при округлении и получить максимально точный суммарный вещественный результат.

**Задача 8 (8.5)** 
Клонирование линии. 
Измените сущность Линия из 2.6.3.
Переопределите метод клонирования, унаследованный от класса Object, таким образом, чтобы при его вызове возвращался новый объект Линии, значения полей которого будут копиями оригинальной Линии. 
**Алгоритм решения:** Заключается в реализации механизма глубокого клонирования для полной независимости копии линии от оригинала. Классы Point и Line подключают интерфейс Cloneable и переопределяют метод clone. Внутри линии сначала создаётся её поверхностный клон через super.clone, после чего принудительно клонируются внутренние точки start и end. Весь процесс оборачивается в блок try-catch для защиты от ошибки CloneNotSupportedException. В результате при изменении координат у клонированной линии оригинал остаётся нетронутым.
