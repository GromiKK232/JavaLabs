Задача 1: Точка координат
Создайте	сущность	Точка,	расположенную	на	двумерной	плоскости,	которая	описывается:	
• Координата	Х:	число	
• Координата	Y:	число	
• Может	возвращать	текстовое	представление	вида	“{X;Y}”	
Необходимо	создать	три	точки	с	разными	координатами	и	вывести	на	экран	их	текстовое	
представление.

Алгоритм: В классе Point создаются приватные поля x и y типа double. 
Конструктор инициализирует эти свойства при создании объекта. 
Переопределенный метод toString осуществляет конкатенацию строк для приведения координат к требуемому формату "{X;Y}". 
В главном методе main создаются три независимых экземпляра класса с разными параметрами, которые автоматически преобразуются в строки при выводе на экран.

Задача 2: Линия 
Создайте сущность Линия, расположенную на двумерной плоскости, которая описывается: 
• Координата начала: Точка 
• Координата конца: Точка 
• Может возвращать текстовое представление вида “Линия от {X1;Y1} до {X2;Y2}” 
Для указания координат нужно использовать сущность Точка, разработанную в задании 1.1. Создайте 
линии со следующими характеристиками: 
1. Линия 1 с началом в т. {1;3} и концом в т.{23;8}. 
2. Линия 2, горизонтальная, на высоте 10, от точки 5 до точки 25. 
3. Линия 3, которая начинается всегда там же, где начинается линия 1, и заканчивается всегда там 
же, где заканчивается линия 2. Таким образом, если положение первой или второй линии 
меняется, то меняется и третья линия. 
4. После создания всех трех объектов измените координаты первой и второй линий, причем 
сделайте это таким образом, чтобы положение третьей линии соответствовало требованиям 
пункта 3. 
5. Измените координаты первой линии так, чтобы при этом не изменились, координаты третьей 
линии.

Алгоритм: Сущность Line содержит два поля ссылочного типа Point.
Если при инициализации третьей линии передать ей те же объекты точек, что используются в первой и второй линиях,
они будут указывать на одни и те же адреса в памяти.
В результате изменение координат исходных точек через сеттеры автоматически изменяет состояние связанных линий.
Для разрыва этой связи  в метод setStart передается новый объект new Point, выделяющий изолированную область памяти.

Задача 3: Студент
Создайте	сущность	Студент,	которая	описывается:	
• Имя:	строка	
• Оценки:	массив	целых	чисел.	
• Может	возвращать	текстовое	представление	вида	“Имя:	[оценка1,	оценка2,…,оценкаN]”	
Необходимо	выполнить	следующие	задачи:	
1. Создать	студента	Васю	с	оценками:	3,4,5.		
2. Создать	студента	Петю	и	скопировать	оценки	Васи,	присвоив	содержимое	поля	с	
оценками	Васи	полю	с	оценками	Пети.		
3. Заменить	первую	оценку	Пети	на	число	5.	Вывести	на	экран	строковое	представление	
Васи	и	Пети.	Объяснить	результат	
4. Создать	студента	Андрея	и	скопировать	ему	оценки	Васи	так,	чтобы	изменение	оценок	
Васи	не	влияло	на	Андрея.

Алгоритм: Поверхностное копирование через передачу vasya.getGrades присваивает Пете прямую ссылку на существующий массив.
Из-за этого оба студента начинают делить один массив оценок на двоих, и изменение данных у одного отражается на другом.
Для создания независимого студента Андрея применяется глубокое копирование с помощью метода Arrays.copyOf.
Он выделяет в куче новый массив-дубликат, благодаря чему последующие изменения оценок Васи никак не влияют на Андрея.

Задача 4(1): Изменение сущности Точка
Измените	сущность	Точка	из	задачи	1.1.	В	соответствии	с	новыми	требованиями	создать	объект	
Точки	можно	только	путем	указания	обеих	координат:X	и	Y.		
Необходимо	выполнить	следующие	задачи:	
• Создайте	и	выведите	на	экран	точку	с	координатами	3;5	
• Создайте	и	выведите	на	экран	точку	с	координатами	25;6	
• Создайте	и	выведите	на	экран	точку	с	координатами	7;8

Алгоритм: Модификация сущности заключается в ограничении способов создания объекта. 
Из класса Point удаляются все альтернативные конструкторы, оставляя единственный конструктор, принимающий два параметра типа double. 
Это гарантирует, что объект невозможно инициализировать без явного указания координат X и Y. 
В методе main новые точки создаются через этот обязательный конструктор.

Задача 4(2): Изменение сущности Линия
Измените	сущность	Линия	из	задачи	2.1.	Новые	требования	включают:	
• Создание	Линии	возможно	с	указанием	Точки	начала	и	Точки	конца	(Точки	из	задачи	4.1)	
• Создание	Линии	возможно	с	указанием	координат	начала	и	конца	как	четырех	чисел	
(x1,y1,x2,y2)	
Создайте	линии	со	следующими	характеристиками:	
1. Линия	1	с	началом	в	т.	{1;3}	и	концом	в	{23;8}.	
2. Линия	2,	горизонтальная,	на	высоте	10,	от	точки	5	до	точки	25.	
3. Линия	3	которая	начинается	всегда	там	же	где	начинается	линия	1,	и	заканчивается	
всегда	там	же,	где	заканчивается	линия	2.

Алгоритм: Для реализации новых требований применяется перегрузка конструкторов внутри класса Line. 
Создается второй конструктор с сигнатурой (double x1, double y1, double x2, double y2). 
Внутри своего тела он автоматически вызывает оператор new для самостоятельного создания начальной и конечной точек Point. 
Это позволяет гибко инициализировать линию в методе main как на основе уже существующих объектов Точек, так и с помощью четырех простых чисел напрямую.

Задача 5: Длина Линии
Измените	сущность	Линия	из	задачи	4.2.	Добавьте	ей	возможность	возвращать	по	запросу	
пользователя	расстояние	между	точками	начала	и	конца	(в	виде	целого	числа).	Создайте	линию	
из	точки	{1;1}	в	точку	{10;15}	и	выведите	на	экран	её	длину.

Алгоритм: Расстояние между точками вычисляется по формуле Евклидова расстояния на двумерной плоскости. 
Программа находит разность координат X и Y начала и конца линии, возводит их в квадрат и суммирует значения. 
Из полученной суммы извлекается квадратный корень с помощью встроенной функции Math.sqrt(). 
Итоговое вещественное число принудительно преобразуется к типу int путем явного отбрасывания дробной части (int).
