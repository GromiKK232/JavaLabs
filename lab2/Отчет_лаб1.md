**Задача 6**: Дана сигнатура метода: public int abs (int x); 
Необходимо реализовать метод таким образом, чтобы он возвращал модуль числа х.
**Алгоритм**: Метод принимает на вход целое число x. Проверяется, является ли это число отрицательным . Если число меньше нуля, то перед ним ставится знак «минус», что меняет знак числа на противоположный (делает его положительным), и этот результат возвращается. В противном случае, если число уже положительное или равно нулю, оно возвращается в исходном виде без изменений.

**Задача 7**: Дана сигнатура метода: public double safeDiv (int x, int y); 
Необходимо реализовать метод таким образом, чтобы он возвращал деление x на y, и при этом гарантировал, что не будет выкинута ошибка деления на 0. 
При делении на 0 следует вернуть из метода число 0. 
**Алгоритм**: Метод принимает на вход два целых числа: делимое и делитель. Сначала проверяется условие — равен ли делитель нулю. Если делитель равен нулю, метод сразу прекращает работу и возвращает 0, чтобы избежать ошибки деления на ноль. Если делитель не равен нулю, то делимое временно приводится к вещественному типу данных для точного деления с сохранением знаков после запятой, после чего выполняется деление и возвращается итоговый результат.

**Задача 19**: Дана сигнатура метода: public int[]add (int[] arr, int x, int pos);

**Задача 20**: Дана сигнатура метода: public int[] add (int[] arr, int[] ins, int pos); 
Необходимо реализовать метод таким образом, чтобы он возвращал новый

Первый цикл копирует элементы из arr в новый массив до позиции pos. Второй цикл поочередно копирует все элементы массива ins, начиная с индекса pos со смещением вправо. Третий цикл дописывает оставшуюся часть массива arr, сдвигая индекс записи вперед на длину вставленного массива ins. Итоговый массив возвращается.
